UX

Definição

UX (abreviação de "User eXperience") é definida como o design estruturado baseado em funcionalidade e criação de protótipos , muitas vezes com uma forma mais crua e sem cor

UI

UI é definida como a forma estética e mais vibrante dos sites, cores, imagens, efeitos e layout que seja auto explicativo, previsível e agradável para chamar a atenção do usuário

o normal quando construir um site, é a criação de uma estrutura elaborada (vários softwaes oferecem ferramentas que ajudam a criar esboços, como o figma ou o canva) para depois elaborar a forma estética, porém, o ideal ficar "não ortodoxo". portanto, é possível concluir que todas as etapas são igualmente importantes, e possuem seu próprio valor, ui sem ux resulta em um site sem forma, inconveniente, e um UX sem UI resulta em um site cru que muitas vezes seria ignorado
